All runs use all 60,000 training images. Modern ablations: seed 37, Adam 0.001, batch 128, ten fixed epochs, no distortions, one final 10,000-image test. No test-driven epoch selection. One seed is not evidence of general superiority.

Historical optimizer: a failed experiment, not a paper match

Appendix C's diagonal Gauss-Newton/Levenberg-Marquardt update was implemented with 500 training samples for curvature, mu 0.02 and the original schedule. Gradients passed autograd parity. The first run saturated C3 and deeper layers, so it was stopped after one pass and 4,507 further examples. It was not test-evaluated. Initialization, loss and curvature behavior remain under investigation. No claim that the paper's optimizer was successfully reproduced.

Where fidelity ends

Exactly 60,000 trainable architecture parameters, sparse C3 Table I, scaled tanh, trainable sum-pooling, 32x32 input with -0.1/1.175 levels, 84-value fixed bitmap RBF outputs. Digit codebooks were reconstructed from printed Figure 3, not recovered digital originals. Pool coefficients initialize at 0.25. Modern libraries, seed and optimizer differ. This is not the full document-reading system or bit-identical historical replication. The paper's augmented 0.8% result is not the relevant baseline for our non-augmented runs.
